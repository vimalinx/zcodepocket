# v1.0.8 源码候选说明（发布草稿）

ZCode Pocket 是独立的第三方 React Native 手机客户端，通过 ZCode 官方 `remote/v4` 公网中转连接用户已授权的电脑工作区。项目源码按 MIT 提供，不分发官方桌面软件、网页包或引擎。

本稿用于维护者审阅，不代表已经打 tag、推送或发布新 APK。建议此次先分享开发版源码；正式 APK 另走签名和实机验收流程。

## 相对已公开 v1.0.6 的变化

- 工作区分组下的新建入口直接创建并打开该工作区的会话，不再重复选择工作区。顶部新建入口仍可选择工作区；创建时防连点，失败不自动重试。
- 升级 URI 解码器与 UUID 修复版，保存 query-string 的 ESM 兼容适配和 image-size 无效容器头保护补丁。
- 图标改为按 Ionicons 子路径导入，避免经总入口带入无关字体；补充相关字体及补丁来源的许可证原文。
- 补充贡献、安全、依赖维护、发行说明、只读权限 CI，以及源码范围和正式 APK 签名检查。

## 边界

- v1.0.7（37）已在用户手机覆盖安装；本次 v1.0.8（38）是更新的源码候选，未安装到手机。
- `bun audit` 仍报告 image-size 的两条 high；对应循环路径已有本地缓解，不能宣称审计零告警或安全认证。
- APK 仍为开发调试签名，不作为正式发行身份。本次不替换现有公开附件，不自动升级手机，也不把候选 APK 标成正式版。
- 移动网络真实会话收发、最新候选实机行为、iOS，以及原生依赖完整 NOTICE 清单仍有待验收的部分。

最新验证与构建信息见 [候选检查](../release-readiness.md)，构建步骤见 [README](../../README.md)。
